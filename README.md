# Komaru Dungeons
> Pixel-art roguelike game with Komaru the cat. Discover the dungeons and defeat enemies.

## About
**Komaru Dungeons** is open-source project written in **C#** using **MonoGame**.

Game is in active development.

## Building
To build project you need:
- .NET 10
- Git

Run the following commands:
### Copying projects from repository:
```bash
git clone https://github.com/obedobedobed/Komaru-Dungeons.git
cd Komaru-Dungeons/KomaruDungeons
```

### Running *debug* build:
```bash
dotnet run
```

### Building project:
```bash
dotnet build
```
